# gravity-forward-modeling

使用 PyTorch 实现三维重力场正演的傅里叶神经算子（FNO），由地下密度差预测地表重力异常，并与棱柱体解析参考值进行逐点对比。网页可交互查看四类棱柱的预计算结果，Windows EXE 支持自定义多棱柱模型和本机实时推理。

## 三维重力场正演工作台

[在线三维演示](https://hjt213.github.io/gravity-forward-modeling/) ｜ [Python 后端源码](https://github.com/HJT213/gravity-forward-modeling/tree/main/github-repo/backend)

## 项目简介

给定地下异常体的位置、尺寸和相对围岩的密度差，正演计算它们在地表各观测点产生的垂向重力异常。工作台包含八字棱柱、单棱柱、分散棱柱和阶梯棱柱四类合成样本，可以查看地下模型，并对照解析参考值、FNO 预测值与两者的差异。

## 在线演示

打开网页后，先选择「八字棱柱」。拖动模型可旋转，滚轮可缩放。勾选「切片位置」并调节左侧滑块，可以在三维视图中定位当前查看的水平切片。鼠标移到任一重力热图上，即可读取同一观测点的参考值、预测值和残差。切换样本后，图表和误差指标会一起更新。

GitHub Pages 提供预先计算的结果，由浏览器绘制三维视图和图表。页面下方可查看像素值直方图和逐像素散点图。

## 技术方案

- **密度建模**　将 20 km × 20 km × 7 km 的空间离散为 64³ 网格，按单元中心采样。棱柱重叠处的密度差相加。
- **棱柱体解析法**　用 Python 和 NumPy 计算各棱柱在地表观测网格上的垂向重力异常，叠加后得到 64 × 64 的解析参考图，单位为 mGal。
- **FNO 推理**　将归一化后的密度差与三维坐标输入 PyTorch 模型，通过傅里叶域谱卷积提取空间特征，再沿深度聚合，输出 64 × 64 的地表重力异常图。模型训练使用 32³ 网格，演示输入为 64³ 网格。
- **可视化与误差分析**　使用 Three.js 绘制三维密度模型，以 Canvas 绘制水平切片和热图。参考图和预测图共用色标。残差定义为预测值减参考值，红色表示正值，蓝色表示负值，白色表示零。

## 四类样本结果

以下为网页内置的四个合成案例的预计算结果。RMSE 表示误差的绝对量级，RRMSE 表示相对于解析参考场均方根的误差，Pearson *r* 衡量两幅重力异常图在各观测点上的线性相关程度。

| 样本 | RMSE（mGal） | RRMSE | Pearson *r* |
| --- | ---: | ---: | ---: |
| 八字棱柱 | 0.118 | 4.83% | 0.9988 |
| 单棱柱 | 0.511 | 22.07% | 0.9703 |
| 分散棱柱 | 0.559 | 7.72% | 0.9971 |
| 阶梯棱柱 | 0.218 | 4.66% | 0.9992 |

每行对应一个 64 × 64 的合成样本，指标用于比较该样本的预测与解析参考值。

## Windows EXE

在 64 位 Windows 上解压完整程序包，双击「三维重力场正演工作台.exe」。启动器会打开默认浏览器，请在使用期间保持启动器运行。程序包内含四类样本、模型权重和 Python CPU 推理环境，可离线运行。

在「自定义建模」中可添加 1–16 个棱柱，输入中心位置、埋深、尺寸和密度差。点击「生成密度模型」查看三维模型与解析参考值，选择合适的 FNO 权重后点击「运行正演」，即可在本机计算预测值并查看误差。[Windows 自定义建模截图](https://hjt213.github.io/gravity-forward-modeling/screenshots/windows-custom.png)

## 仓库结构

- `index.html`、`app.js`、`density-3d.js` 和 `style.css` 实现网页界面、绘图和三维交互。
- `demo-data/` 保存四类样本的三维密度网格、解析结果、FNO 预测和误差指标。
- `backend/` 包含棱柱体解析算法、FNO 模型、演示数据导出脚本和本机推理接口。
- `backend/desktop/` 包含 Windows 启动器与打包脚本，`screenshots/` 保存界面截图。
